# Answer Key (Teacher's Copy)

> All numerical answers below were verified symbolically with SymPy.

### Part A

**1.** a) Yes — every ratio `distance / time = 35`, constant.
   b) `k = 35` (km/h).
   c) `d = 35 · t`.

**2.** With `k = 3`: `y = 3x`.
   - `x = 4 → y = 12`
   - `y = 21 → x = 21 / 3 = 7`
   - `x = 10 → y = 30`
   So the completed table is **x: 2, 4, 7, 10** and **y: 6, 12, 21, 30**.

**3.** `x = (4 · 25) / 10 = 100 / 10 = ` **10**.

**4.** Coefficient `k = 150 / 4 = 37.5` g per cookie.
   For 18 cookies: `18 · 37.5 = ` **675 g**.

**5.** a) **Proportional** — every ratio `y / x = 3` is constant (k = 3).
   b) **Not proportional** — ratios are `3/1 = 3`, `4/2 = 2`, `5/3`, `6/4 = 1.5` — not constant.
   (In fact `y = x + 2`, which is an *additive*, not multiplicative, relation.)

### Part B

**6.** `25/100 · 80 = ` **20**.

**7.** `15 / 60 = 1/4 = ` **25 %**.

**8.** `200 · (1 + 12/100) = 200 · 1.12 = ` **224 €**.

**9.** `50 · (1 − 20/100) = 50 · 0.80 = ` **40 €**.

**10.** `30/100 · 250 = ` **75 students**.

### Part C

**11.** Like-term groups:
   - In `x²`: `3x²`, `5x²`, `2x²`
   - In `x`: `−2x`, `−4x`
   - Constants: `7`, `−1`

**12.** Group like terms: `(5x − 2x − x) + (3 + 7 + 4) = ` **`2x + 14`**.

**13.** `E + F = (4x + 7) + (3x − 2) = (4x + 3x) + (7 − 2) = ` **`7x + 5`**.

**14.** `3 · (2x + 5) = 3·2x + 3·5 = ` **`6x + 15`**.

**15.** `(x + 3)(x + 2) = x² + 2x + 3x + 6 = ` **`x² + 5x + 6`**.

**16.** `E(2) = 2·(2)² + 3·(2) − 1 = 8 + 6 − 1 = ` **13**.

### Bonus

`80 · 0.75 = 60`, then `60 · 1.25 = 75`. Final price is **75 €**, **not** 80 €.
Reason: the 25 % increase is applied to the *reduced* base (60), not the original 80,
so successive equal % changes do **not** cancel out.
